# Brightspace Dark+ Privacy Policy

Effective date: September 20, 2026

Brightspace Dark+ is an unofficial browser extension that applies a dark visual theme to D2L Brightspace learning environments.

## Information the extension accesses

To apply the theme, Brightspace Dark+ accesses the structure and visible content of a Brightspace site after the user explicitly enables the extension for that site's HTTPS domain. This processing happens only inside the user's browser and is limited to changing presentation, contrast, colours, and related interface styling.

When the extension toolbar button is opened, a temporary `activeTab` grant is used to check for general Brightspace/D2L interface markers. The check returns only a yes-or-no result and is not stored or transmitted. If Brightspace is detected, the user may grant persistent access to that specific site. The extension does not request access to other sites, browsing history, identity, location, financial information, or authentication credentials.

## Site permission choices

Chrome retains the user's site-access decision as an extension permission. Brightspace Dark+ registers its packaged theme for the enabled domain so it can run on future visits. Users can remove that access from the extension popup or Chrome's extension settings. Brightspace Dark+ does not keep its own list on an external server and does not use Chrome Sync or extension storage.

## Collection, storage, and sharing

Brightspace Dark+ does not collect, copy, store, transmit, sell, or share personal information, browsing activity, course content, grades, form entries, or other website content. It does not use analytics, advertising, tracking, remote code, or external servers. No user data is retained by the extension.

## Purpose and limited use

Any Brightspace page information handled locally is used only to provide the extension's single purpose: displaying an enabled Brightspace site with an accessible dark theme. It is not used for advertising, profiling, credit decisions, or any purpose unrelated to the extension's visible functionality, and it is not made available to people or third parties.

Brightspace Dark+'s use of information complies with the Chrome Web Store User Data Policy, including its Limited Use requirements.

## Changes to this policy

If a future version changes how information is handled, this policy and the Chrome Web Store disclosures will be updated before that version is published.
